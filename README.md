# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Personal Project Showcase App

## Description

The Personal Project Showcase App is a web application that allows users to create, display, and manage their personal projects in one place. It provides a simple and user-friendly interface for adding projects and exploring existing ones.

## Features

- Add new projects using a form.
- Display created projects as horizontal cards.
- Search for specific projects.
- View project titles and descriptions.
- Responsive design for different screen sizes.
- Simple and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React (if implemented)
